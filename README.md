# Pay-to-Vote Blockchain System

## Project Title

Pay-to-Vote Blockchain System

## Project Description

Pay-to-Vote Blockchain System is a decentralized voting platform built using Soroban smart contracts on the Stellar blockchain. The system allows users to vote for candidates by paying a fixed voting fee of 1 XLM (or a test token). Each vote is securely recorded on-chain, ensuring transparency, immutability, and fairness throughout the election process.

The platform prevents duplicate voting, tracks voting fees collected, and automatically determines the winning candidate based on the total number of votes received.

---

## Project Vision

The vision of Pay-to-Vote Blockchain System is to provide a transparent, secure, and decentralized election mechanism where every vote is authenticated and recorded on-chain. By integrating blockchain-based payments with voting, the system minimizes fraud, prevents spam voting, and ensures trustworthy election results.

## Key Features

### Pay-to-Vote Mechanism

* Each vote requires a payment of 1 XLM or a supported token.
* Voting fees are automatically collected by the smart contract.

### Candidate Voting

* Users can vote for Candidate KHÁNH or Candidate THƯ.
* Votes are counted in real time.

### One Wallet, One Vote

* Prevents duplicate voting from the same wallet address.
* Ensures fairness in the election process.

### Automatic Winner Selection

* The smart contract automatically determines the winner based on vote count.

### Transparent Results

* Anyone can view voting results and total fees collected.

### Immutable On-Chain Records

* All votes and election data are permanently stored on the Stellar blockchain.

* Users must authorize transactions using their wallet signatures.
